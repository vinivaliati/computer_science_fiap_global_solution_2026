### ✅ Global Solution — Sistema Inteligente de Monitoramento Orbital

[Acessar README do 1º Semestre](./1_semestre/readme.md) · [Acessar Relatório](./1_semestre/docs/relatorio.md) · [Assistir ao Vídeo](https://youtu.be/Su2JB2KjFdw)

Simulação de um **sistema de monitoramento operacional** para a Estação GB-1, uma estação orbital experimental em órbita baixa terrestre. O sistema interpreta dados de telemetria, classifica situações críticas, gera alertas automáticos e prevê o comportamento da reserva de bateria usando regressão linear com média móvel.

O projeto inclui:
- Processamento de **1086 leituras de telemetria** (Jan–Jun 2026) cobrindo 6 módulos críticos
- Estruturas de dados: lista, fila, pilha, dicionário, hierarquia e matriz
- **Expressão booleana** para diagnóstico de status NORMAL / ALERTA / CRÍTICO
- Detecção de inconsistências e anomalias nos sensores
- **Regressão linear** com média móvel para previsão de 48h da reserva de bateria
- Recomendações automáticas por causa e nível de criticidade
- Implementado em Python puro, sem bibliotecas externas além de `csv` e `os`
